## 先に結論
- このサイトの作例は「動画を作るためのプロンプト」で、サイトの部品集ではない。しかも大半は「15秒のモーショングラフィックス動画を作って」といった短い一文だけで、動きの指示が書かれていない（下表の「中身薄い」）。
- 動きの具体指示が読めたのは twoclipping 氏の4本と notdwd 氏の1本。SaaS／Apple基調発表の雰囲気が強く、動物カフェには直接は合わない。
- よって採用候補は「考え方」だけ借りる。10個以内で、いずれも操作に応じた小さな動きに絞った。

## 採用候補（9個）
共通ルール: すべて `@media (prefers-reduced-motion: reduce)` では時間0（即座に最終状態）。`transform` と `opacity` だけを動かす。ばね・行き過ぎは使わず、イージングは ease-out（cubic-bezier(.2,.7,.2,1) 目安）。

1. 読み込み時の見出し一括せり上がり（1箇所だけ）
   - 元: twoclipping-6dd14e の「マスクから文字がせり上がる」、twoclipping-221cab の「マスクからせり上がる」
   - 使う場所: トップの見出しとヒーロー周りのタイルを、ページ読み込み直後に1回だけ。
   - 動き: 8px下から opacity 0→1 と移動、0.4秒、ease-out。タイルは 40ms ずつずらして最大6個まで（合計0.65秒以内）。再生後は二度と動かない。スクロール連動はしない。
   - 合う理由: 「ふわっと並ぶ」程度で、読み込みの瞬間が統一される。
2. 絞り込みチップの押下と選択状態の切り替わり
   - 元: twoclipping-5cba86 の「タブの選択印が隣へ伸びて移る」（左右の端を別々に動かす発想）
   - 使う場所: 動物種・エリア・条件のチップ。
   - 動き: 選択印（背景のやわらかい丸み）が 0.2秒で隣へスライドする。押した瞬間に 0.97 倍に縮み、0.12秒で戻る。
   - 合う理由: 押した手応えが出る。派手さがなく、行き過ぎもない。
3. 絞り込み結果の並び替わり（FLIP）
   - 元: twoclipping-221cab の「グリッドが組み替わって別の配置になる」発想
   - 使う場所: 店舗カードの一覧。
   - 動き: 残るカードは新しい位置へ 0.25秒で滑って移動。消えるカードは 0.15秒で opacity 0、新規は 0.2秒で opacity 0→1。距離は元の位置から新しい位置までそのまま。大きく飛ばさない。
   - 合う理由: 結果が「どう変わったか」を目で追える。
4. カードの2px浮き
   - 元: twoclipping-d89be5 の「カードがページから少し浮く」の弱め版
   - 使う場所: 店舗カード（ホバーとキーボードフォーカス）。
   - 動き: translateY(-2px)、0.15秒。影はわずかに濃くなるだけ。他の変化（拡大・光）はなし。
   - 合う理由: 制約の「2px浮く」そのまま。
5. 数字のカウントアップ（操作時のみ）
   - 元: twoclipping-5cba86 の「スライダーを引くと値が追従する」
   - 使う場所: 絞り込み後の「◯件」表示。
   - 動き: 前の件数から新しい件数まで 0.3秒で数え上げ（ease-out）。ページ読み込み時の自動カウントアップは付けない。
   - 合う理由: 絞り込みが効いたと分かる。件数の変化が大きくても短く終わる。
6. ハート（お気に入り）とコピー（住所・URLコピー）の押下フィードバック
   - 元: twoclipping-5cba86 の「ボタンがチェックに形を変える」「完了のトースト」
   - 使う場所: ハートボタン、コピーボタン。
   - 動き: 押すと 0.97 倍に縮み 0.12秒で戻る。ハートは色が塗り替わるだけ（弾ませない）。コピーはアイコンがチェックに 0.15秒で入れ替わり、1.5秒後に元へ戻る。小さな札「コピーしました」が opacity だけで 0.2秒表示。
   - 合う理由: 操作の結果が確かに伝わる。
7. 検索窓のプレースホルダ切り替え
   - 元: notdwd-c2037d の「検索窓に打ち込まれる文字」
   - 使う場所: トップの検索窓。
   - 動き: 窓が空でフォーカスされていない間だけ、「ねこカフェ 渋谷」「ふくろう 触れる」などを 3.5秒ごとに入れ替える。入れ替えは 0.25秒で縦に 6px ずらしながら opacity。フォーカスした瞬間に止める。
   - 合う理由: 使い方の例を、やわらかく見せられる。ただし常時動くので reduced-motion では完全に固定し、スクリーンリーダーには固定の説明を付ける。念のため「ページ読み込み時の動き」には数えず、最小限にしたい場合は見送りでよい（要判断）。
8. 検索窓・ボタンのフォーカス/ホバー時の小さな拡大（ボタンのみ）
   - 元: notdwd-c2037d の「カーソルが近づくとロゴが育つ」
   - 使う場所: 主ボタン（「探す」など）。
   - 動き: ホバーで 1.03 倍、0.15秒。カードには使わない。
   - 合う理由: 押せる物だと伝わる。カードには付けず、範囲を限る。
9. 結果が0件のときの空状態
   - 元: twoclipping-5cba86 の「状態が入れ替わるときに中身だけ短くぼかして入れ替える」の弱め版（ぼかしは使わず opacity のみ）
   - 使う場所: 絞り込みで0件になったとき。ドット絵の動物（座ってこちらを見る）と「条件を少しゆるめてみてください」の文を出す。
   - 動き: 0.25秒で opacity 0→1、4px 上へ。ドット絵はまばたき 1回だけ（0.15秒）を、表示の 1.2秒後に1度行う。繰り返さない。
   - 合う理由: 行き止まりでも冷たくならない。

補足（ドット絵の待機動作）: 常時動くのでサイトの全体方針（動きは操作に応じるものを歓迎）とは別枠。使うなら「ヒーローのキャラ1体だけ、5〜8秒に1回まばたき（steps() で2コマ）」まで。今回の作例からは具体指示を得られなかったため、自前設計。

## 見送った動きと理由
- 1つの図形が全部の状態へ変形し続ける（twoclipping-5cba86）: 動画用の演出で、サイトの部品構成に合わない。
- ばね（行き過ぎ）・「液体のように伸びる」: バウンスに近く禁止。
- カメラのズーム、3D俯瞰、カードが立ち上がる、ガラスの質感（twoclipping-d89be5 / 221cab / notdwd）: 3D・テック感・SaaS調で見送り。
- 光る輪、発光の文字、黒背景の締め（notdwd）: グロー禁止。
- 虹彩（絞り）で場面を切る、画面全体を黒で塗りつぶして次へ（twoclipping-221cab）: ページ遷移としては派手すぎ。ページ遷移は通常の切り替えで十分。
- 拍に合わせた文字出し、スキャン線、ティッカー（twoclipping-6dd14e）: 点滅・テック感。動画の拍に依存。
- ぼかしの遷移、モーションブラー: 描画負荷と読みづらさ。reduced-motion 対応も難しい。
- ショーリール系（stephanlivera / shneural / himanshutwtxs / jacksonfall / davidmarcus / thismacapital）: 指示が短く、パーティクル・太い文字の勢い重視で動物カフェの雰囲気に合わない。
- スクロール連動の全般（twoclipping-d89be5 の飛行など）: 禁止。
