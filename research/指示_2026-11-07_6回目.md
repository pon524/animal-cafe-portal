## 目的
オーナーから「まだありそうだから、もっと探して」と言われた。いま366店。
前回までの弱点は2つ：
1. **チェーン店の支店を全部は拾えていない**（例：猫カフェMOCHA は18店しか無いが公式の店舗一覧はもっと多い。猫喫茶 空陸家 は8店、Moff animal cafe は35店。にゃんくる・きゃらふ・ねこぶくろ・きゃりこ・てまりのおうち・猫の居る休憩所299 は1店も入っていない）
2. **市区町村名で探していない**（「東京都 猫カフェ」では上位の店しか出ない。「練馬 猫カフェ」「町田 犬 ふれあい」「船橋 保護猫カフェ」のように区・市の名前で引くと別の店が出る）
「東京・大阪が多いから見送る」「件数のバランスで見送る」は禁止。公式で確認できた店は全部入れる。

## 必ず読む
- `運用マニュアル.md` の「全員の禁止事項」「2. データの決まり」（JSON の項目、features の語彙、price_level、reservation、掲載対象の定義、id の形式、説明文は「だ・である」調2〜3文）
- 既存の店は `data/cafes/*.json` に入っている。**同じ店を二重に入れない**。開始時に次で名前一覧を出して控える：
  `cd /Users/suzukiissei/ClaudeCode/animal-cafe-portal && python3 -c "import json,glob;[print(c['prefecture'],c['name'],c['url']) for p in glob.glob('data/cafes/*.json') if '/_' not in p for c in json.load(open(p))]"`
- 自分の担当エリア・動物の過去メモ `research/<動物>_調査メモ.md` の「見送り」も読む。見送りの理由が「公式に到達できず」なら、今回は検索語を変えて（店名＋市名、店名＋「公式」、店名＋instagram）もう一度だけ試す。

## 探し方（重要）
1. **WebSearch** を主な道具にする。
   - チェーン担当：公式サイトの「店舗一覧」ページを開き、全店舗を書き出し、既存データと突き合わせ、無い店を店舗ページで確認して追加する。
   - エリア担当：担当の**区・市の名前**×「猫カフェ」「犬カフェ ふれあい」「保護猫カフェ」「保護犬カフェ」「ふくろうカフェ」「うさぎカフェ」「ハリネズミ カフェ」「爬虫類カフェ」「小動物 カフェ」「アニマルカフェ」「動物 ふれあい 屋内」を回す。大きな市は区名まで下りる（横浜市なら港北区・戸塚区…、名古屋市なら中区・千種区…）。
   - 1つの市で何も出なければ次へ。出たら周辺の市でも同じ語を試す。
2. 候補が出たら **WebFetch** か `curl -sL -A "Mozilla/5.0" <url>` で公式サイトを開き、料金・営業時間・住所・予約を確認する。公式サイトの JS 描画で本文が読めないときは `curl` の生 HTML から `grep` で拾う。
3. 公式サイトが無い店は、公式 Instagram / X / Facebook の投稿が **6か月以内**にあれば SNS を正本にしてよい（マニュアル参照）。Instagram は未ログインで本文が読めないことが多い。読めなければ「見送り（Instagram のみで料金が確認できず）」と記録する。X は `https://syndication.twitter.com/srv/timeline-profile/screen-name/<id>` で読めることがある。
4. まとめサイト（じゃらん、asoview、ホットペッパー、食べログ、Google マップの口コミ、ブログ）は**候補を見つける入口としてだけ使う**。載せる数字は必ず公式で確認する。公式に料金が画像でしか無い場合は、画像の説明文や alt、運営会社名義のプレスリリースから読める料金なら採用してよく、source_note にそう書く。モール内の店はモール公式の店舗案内ページを正本にしてよい。
5. 同じサイトへの連続アクセスは2秒以上あける。CAPTCHA・ログインの壁は越えない。アカウント登録・フォーム送信・予約・問い合わせはしない。オーナーのメールアドレスや個人情報を外部に送らない。Bing や DuckDuckGo を curl で引かない（WebSearch ツールを使う）。

## 掲載する／しないの境目
- 載せる：料金を払って店の動物とふれあえる店・屋内施設。飲食の有無は問わない。予約制でもよい。保護猫・保護犬カフェも載せる（features に「保護動物」「里親募集」）。
- 載せない：客が自分の犬を連れて行く「ドッグカフェ」「ドッグラン」（店の犬がいない）、ペットショップ、ブリーダー見学、動物園・牧場そのもの、閉店・休業中・開店前の店、料金が公式で確認できない店。
- 移転予定の店は、公式に新住所と営業開始日が出ていて今日以前なら新住所で載せる。未定なら見送り。
- 公式サイトが古い（2年以上更新なし、動物取扱業の有効期限切れ表記）で、公式SNSにも6か月以内の投稿が無ければ見送り（理由を書く）。

## データの書き方の補足
- `animals` の先頭は主な動物（dog / cat / rabbit / owl / bird / hedgehog / otter / capybara / reptile / smallanimal / farm / other）。犬猫両方なら主な方を先頭に。
- `checked` は "2026-11-07"。
- `price` は税込の表記をそのまま要約（例：「60分1,650円（1ドリンク付き）」）。`price_level` は平日の1時間目安（ドリンク別なら足す）：1=〜1,000円、2=〜2,000円、3=〜3,000円、4=それ以上。
- `reservation` は公式に予約の案内が無ければ「不要」。公式が勧めていれば「推奨」。予約がないと入れないなら「必須」（このときだけ features に「予約制」）。
- `description` は「だ・である」調2〜3文。動物の種類・頭数・店の特徴を具体的に。公式の文章の丸写しは禁止。人名は書かない。チェーン店でも支店ごとに書き分ける（フロア、頭数、モール内か路面か、など）。
- `source_note` に確認した公式ページのURLと、記載が無かった項目を書く。
- 公式に記載が無い `closed` や `access` は「公式ページに記載なし（来店前に確認を）」。最寄駅が分からなければエリア名だけ。「徒歩すぐ」などの推測は書かない。
- `image` は null。
